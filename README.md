# Pavel Angelov - Portfolio

Personal developer portfolio built with Vite, GSAP (ScrollTrigger, SplitText, ScrambleText, MotionPath) and Lenis smooth scrolling.

## Development

```sh
npm install
npm run dev      # http://localhost:5173
npm run build    # production build in dist/
npm run preview  # serve the production build
```

## Structure

- `index.html` - page markup and content
- `src/style.css` - styles
- `src/main.js` - scroll animations, smooth scrolling and interactions
- `public/` - static files (CV download)
